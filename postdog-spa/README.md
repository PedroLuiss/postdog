# 🚀 React Delivery System

Este proyecto es una aplicación basada en **React** para la gestión eficiente de entregas. Su objetivo es mejorar el seguimiento de pedidos, optimizar rutas y ofrecer una experiencia fluida tanto para usuarios como administradores.

## 📂 Estructura del Proyecto

- `/src/components` → Componentes reutilizables  
- `/src/pages` → Páginas de la aplicación  
- `/src/assets` → Íconos, imágenes y estilos  
- `/src/utils` → Funciones auxiliares  
- `/src/services` → Llamadas a APIs  

## 🔧 Tecnologías Utilizadas

- **Create App React**  
- **React Router** (manejo de rutas)  
- **Styled Components / Bootstrap CSS**    
- **Context API**  

## 🛠 Instalación y Ejecución

1️⃣ **Clonar el repositorio:**  
```sh
git clone <URL_DEL_REPO>
```

2️⃣ **Instalar dependencias:**  
```sh
npm install
```

3️⃣ **Ejecutar el proyecto:**  
```sh
npm run dev
```
Abre [http://localhost:5173](http://localhost:5173) para visualizarlo en tu navegador.

## 🔬 Pruebas

Ejecuta los test con el siguiente comando:  
```sh
npm test
```

## 🚀 Despliegue

Para generar una versión optimizada para producción:  
```sh
npm run build
```
Esto creará una carpeta `/dist` lista para ser desplegada.
